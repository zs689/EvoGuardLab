## 结论与边界

- 留出集上候选与默认的 F1 都是 1.0，说明**合成开发集区分度不足**，不能据此判定候选更优；这也是候选不启用的直接理由。
- 候选配置写在 `config/thresholds_v2_calibrated.json`，**未启用**；默认仍是 `thresholds-v1 / 20%`，不改写历史可比数字。
- 开发集是**合成健康度快照**，不是真实业务轨迹；标定结果只说明「在这批快照上哪个阈值最合适」，不宣称生产可用。
- 要启用候选值，需要真实开发集分布 + 误报案例复核 + 人工确认。
- 候选阈值未启用；默认仍为 thresholds-v1 / 20%，不改写历史可比数字。启用需人工确认。
