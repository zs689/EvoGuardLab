## 三、跨 Agent 迁移

- 架构现状：**不允许**（runtime._decide 要求 skill.task_type == agent_type；order 的技能直接用到 kb/planner 时不会被采用。）
- 模拟迁移（把 `task_type` 改成目标 agent）：18 条成对用例，增益 0.0、负迁移率 0.0、判定 **REJECT**
- 把 task_type 改成目标 agent 是**模拟**迁移，不等于架构已支持；业务收益不能抵消负迁移。

## 边界

- 三件事分开报，不合成一个分数。
- 多 seed 与迁移实验都在临时 SQLite 库上跑，不碰仓库 `data/`。
- 仿真的确定性不代表真实模型稳定；迁移实验是模拟，不是已打通的能力。
