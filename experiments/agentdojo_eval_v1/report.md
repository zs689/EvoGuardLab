# AgentDojo 攻击模板：覆盖矩阵 + 跨数据集检验

> 语料：`ethz-spylab/agentdojo`（**MIT**），按 git blob sha 取 4 个源码文件，AST 静态解析字符串常量，不 import、不执行。
> 生成 120 条**组合样本**：10 个模板 × 12 个攻击目标（目标取自 InjecAgent）。

## 跨数据集检验怎么读

- 二级模型只在 **InjecAgent** 上训练，从未见过 AgentDojo 的模板；这里的命中率是真正的跨语料泛化，不是同一批数据的另一份切分。
- 一级正则只认字面注入话术，`important_instructions` / `direct` / `dos` 这类没有关键词的模板会漏 —— 和 InjecAgent base 变体的 0 召回是同一个问题。
- 组合样本不是独立攻击向量：同一个模板换 goal 不算新的攻击手法，不能拿去凑「30 个独立向量」。

## 边界

- 模板里的 `{goal}` 用 InjecAgent 的攻击句填充，因此是**两套公开语料的组合**；结论只适用于「措辞包装」这一维。
- `SwearwordsDoSAttack` 内容不雅且与检测能力无关，解析时跳过；`ManualAttack` 需要人工输入，也跳过。
- 语料与样本都不入库（`data/external/` 已忽略），清单记录逐文件 sha256。
