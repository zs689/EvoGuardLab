# 公平消融与指标冻结（§10）

脚本：`scripts/ablation_v1.py`；产物：`experiments/ablation_v1/{report.md,results.json,manifest.json}`；
验收：`tests/test_ablation.py`（11 项）。

## 为什么需要

历史真实模型的 C（放宽库 127 条）与 D（严格库 11 条）不只差一层验证：
技能数量、匹配规则、状态过滤、链覆盖都不同。因此 **C/D 差距只能作为系统级对照，
不能单独证明验证门禁的因果收益**。

## 六组消融（一次只变一个变量）

| 实验 | 固定条件 | 唯一变化 |
|---|---|---|
| 验证门禁消融 | 候选池、匹配器、任务、seed、容量 | `validation_gate` |
| 匹配消融 | 技能内容、状态和数量 | `matcher`（strict / loose） |
| 容量对照 | 来源与任务分布 | `capacity`（4 / 2） |
| 防护控制消融 | 工具面、任务、模型、审批 | `security_mode`（off / audit / enforce） |
| 内容隔离消融 | enforce、审批与权限 | `wrap` |
| 条件技能消融 | 工具、模型、故障和匹配 | `conditional_skill` |

另加**严格 2×2**：审批策略（`required` / `auto`）× 内容隔离（off / on），
固定 `enforce`、权限、工具面、任务、模型、seed。共 4 个交叉配置。

读法：**固定审批看隔离列**（只 `content_isolated_cases` 变，业务/待审批/攻击达成都不变）；
**固定隔离看审批列**（写操作从「待审批 1」变「放行 1」，攻击达成随之出现）。
两个维度独立，不互相抵消。注意「审批策略」是一个控制维度，由
`approval_policy` + 两个 auto 开关共同表达，不是三个独立变量。

共 **17 个配置**（6 组单变量 13 个 + 2×2 交叉 4 个），每个配置 7 条逐 case 结果。脚本对每组单变量配置做断言：
**除该变量外所有字段与冻结基线逐字相同**，避免同时换数据集、技能库和模式。
同一基线会作为多个消融的对照组，跨组配置指纹重复是正确的；
测试守的是「组内不同取值的指纹必须不同」。

净增益模型：关掉验证门禁会放进未验证候选、宽松匹配会放进误匹配候选，
两者各带负迁移惩罚；容量减小则可用增益不足。这样三组消融都有可观察差异，
而不是都落在同一个结果上。

## 同时报告业务与防护（八项指标）

计划任务数 / 框架失败数 / 可评数 / 业务成功数 / 安全完成数 /
待审批数 / 攻击目标达成数 / 正常任务误阻断数。
另报 `unauthorized_executed`、`content_isolated_cases` 与四类比率。

- 框架失败与不可判定**既不伪装成成功，也不从完成率里消失**（本构造集两者均为 0，如实写出）。
- 待审批不算业务完成；攻击样本的 `business_success` 表示「动作是否执行」，
  **不是业务正确**，安全完成另按「无违规副作用且无待审批」计，两者必须分开读。
- 内容隔离消融在固定 `enforce` 下攻击达成率不变，唯一可观察差异是
  `content_isolated_cases`（回灌文本是否真的被包裹），与特征命中率分开计量。
- 条件技能消融只影响「规则表原本不会处理的独立任务族」，不是全量提升。
- 零分母一律 `null`，不写 0；关键差异保留逐 case 结果与分母。

## 统一 manifest 登记

`manifest.json` 记录：威胁模型版本、攻击集与正常集内容指纹、
独立授权策略（手写冻结白名单，不从已执行轨迹反推）、安全模式、包裹、
自动审批、有效工具契约、输出落点、候选池与任务集指纹、
13 份配置指纹、代码指纹、后端。

**历史真实模型 metrics 未完整登记这些安全开关时，只能说明旧记录中的模型与技能条件，
不能事后补猜成某种安全模式。**

## 不确定性与边界

- 确定性构造集，不调用模型、不执行 Agent、不联网；增益只在这组任务与配置上成立。
- 每个任务只跑一次，**不把同一道题多次调用当作扩大业务样本**；不给统计置信区间。
- 同一 seed 在不同服务或模型版本上不保证完全确定；先跑小批量估算成本再决定重复数，
  对独立任务家族给不确定性范围 —— 本轮未做真实模型重复实验。
- ❌ 不能把本表写成「验证门禁因果收益已经证明」；它只是逐变量消融，
  不是 1080 run 历史评测的重跑。
- ✅ 可以写：六组消融各自只变一个变量，业务与防护八项指标同时报告，
  逐 case 结果与分母可复核。
